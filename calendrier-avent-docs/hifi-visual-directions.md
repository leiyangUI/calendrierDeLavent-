# Hi-Fi Interface Design — 视觉方案

本次只讨论 Hi-Fi Interface Design 的视觉方案，不生成图片，也不做 moodboard。

「欢快」是第一视觉原则：打开产品时，孩子应该感到兴奋、温暖，像收到一份圣诞礼物，而不是打开一个普通的日历应用。

基于已经确定的产品结构：

- **B** 是默认首页
- **A** 是整月日历
- **C** 是独立每日页面

以下是三个不同的高保真视觉方向，都能共用同一套组件和交互逻辑。

---

## 01 — Christmas Candyland

**最欢快 · 首推**

**关键词：** 糖果、礼物、彩色、庆祝、惊喜

这是一个色彩丰富、非常有节日气氛的儿童圣诞世界。视觉上更接近一份精心包装的圣诞礼物。

### 视觉语言

| 元素 | 设计方向 |
| --- | --- |
| 主色 | 圣诞红、糖果粉、薄荷绿 |
| 辅色 | 奶油黄、天空蓝、暖白 |
| 背景 | 柔和奶油色，搭配彩色装饰 |
| 卡片 | 大圆角、礼物盒造型、轻微阴影 |
| 字体 | 圆润、粗体、儿童友好 |
| 装饰 | 糖果、星星、蝴蝶结、雪花 |

### B：首页设计

- 顶部：`Bonjour ! 🎄`，搭配醒目的圣诞倒数标题。
- 中间：今天的礼物卡片，占据主要视觉空间。
- 今日礼物使用大尺寸彩色礼物盒，带有蝴蝶结。
- CTA：`Ouvre ton cadeau !`
- 下方：24 个小礼物格子，形成可以探索的日历。

### A：整月日历

24 个礼物盒组成网格。今天的礼物更大、更亮，已经开放的日期显示打开的礼物，未来日期显示带锁的礼物。

### C：每日独立页面

每天像打开一张圣诞贺卡。内容区域采用大面积留白，配合彩色插画和明确的返回、前后日期导航。

**适合：** 希望产品第一眼就非常活泼、吸引儿童主动探索的方向。

---

## 02 — The Christmas Toy Village

**最有故事感**

**关键词：** 童话村庄、玩具、雪景、角色、探索

这里不是糖果世界，而是一座充满生命力的圣诞玩具小镇。24 天就像 24 个等待探索的小房子。

### 视觉语言

| 元素 | 设计方向 |
| --- | --- |
| 主色 | 森林绿、朱红、天空蓝 |
| 辅色 | 明黄、奶油白、粉橘 |
| 背景 | 浅蓝雪景或暖白 |
| 卡片 | 小房子、窗户、门、屋顶 |
| 字体 | 友好圆润，带一点童话气息 |
| 装饰 | 小雪人、圣诞树、灯光、动物角色 |

### B：首页设计

- 首页呈现一座圣诞小镇。
- 今日房子被灯光照亮，门上标记日期。
- 点击房子，进入今天的惊喜。
- 下方显示一个精简的 24 天探索入口。

### A：整月日历

将 24 个日期设计成 24 座小房子。开放的房子亮着灯，未开放的房子有雪覆盖。

### C：每日独立页面

每一天都是小镇里的一个地点：玩具工坊、糖果店、邮局、圣诞树广场等。内容和地点形成连续的故事体验。

**适合：** 希望孩子不仅每天打开内容，还能逐渐熟悉一个有连续感的圣诞世界。

---

## 03 — Christmas Party Pop

**最现代 · 最有活力**

**关键词：** 派对、气球、贴纸、动感、庆祝

这是一个更现代、更大胆的儿童数字产品方向。它不像传统圣诞插画，更像一个专为圣诞节设计的欢乐互动空间。

### 视觉语言

| 元素 | 设计方向 |
| --- | --- |
| 主色 | 亮红、亮绿、明黄 |
| 辅色 | 蓝色、粉色、橙色 |
| 背景 | 大色块和柔和渐变 |
| 卡片 | 不对称布局、大圆角 |
| 字体 | 大号、粗体、视觉冲击力强 |
| 装饰 | 彩纸、贴纸、星星、几何图形 |

### B：首页设计

- 大标题：`C'est bientôt Noël !`
- 今日内容采用大号彩色卡片。
- 24 天网格像一张圣诞派对邀请卡。
- 按钮使用鲜明色块和大尺寸触控区域。

### A：整月日历

日期以不同颜色的卡片呈现，不是传统的统一方格。今天的日期使用动态感更强的视觉强调。

### C：每日独立页面

每一天采用不同的主题色，但保留统一的组件结构。阅读、故事和活动内容都有明确的视觉层级。

**适合：** 希望产品看起来更像现代儿童数字体验，而不是传统圣诞贺卡。

---

## 三个方向的比较

| 维度 | Candyland | Toy Village | Party Pop |
| --- | --- | --- | --- |
| 欢快程度 | 非常高 | 高 | 非常高 |
| 圣诞氛围 | 非常强 | 非常强 | 强 |
| 童话故事感 | 中 | 非常强 | 低 |
| 现代数字产品感 | 高 | 中 | 非常高 |
| 24 天探索感 | 礼物探索 | 世界探索 | 派对探索 |
| 视觉统一性 | 高 | 高 | 高 |

---

## 建议

选择 **01 Christmas Candyland 作为主视觉，再吸收 02 的一点故事感**。

原因：产品核心是每天打开一份惊喜。礼物盒、糖果色和庆祝感，比一整座小镇更直接地表达这个动作。

最终视觉系统建议采用 **Christmas Candyland — Final Art Direction**。

**建议色彩：** 圣诞红、薄荷绿、奶油黄、天空蓝、奶油白

### 关键界面原则

- 今日礼物必须是首页视觉焦点。
- 24 个日期必须一眼可识别、容易点击。
- 未来日期的锁定状态要有期待感，而不是惩罚感。
- 所有按钮、日期卡片都要有明显的交互状态。
- 插画负责营造氛围，不能挤压内容的可读空间。
- A、B、C 三种视图共享一套颜色、字体、卡片和状态系统。

### 下一步

先确定三个方向中的一个，再把它落实成真正的 Hi-Fi UI Specification：B 首页、A 月历、C 每日详情三套界面的布局、尺寸、颜色、字体、组件状态和交互细节，而不是停留在视觉概念上。
