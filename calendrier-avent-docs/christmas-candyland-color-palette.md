# Christmas Candyland — Final Art Direction

颜色 HEX 色值建议

## Color Palette

| 名称 | HEX | 用途 |
| --- | --- | --- |
| **Christmas Red** | `#F04452` | 主色 · 今日礼物、重要 CTA |
| **Mint Green** | `#38B879` | 主色 · 开放日期、成功状态 |
| **Cream Yellow** | `#FFD45A` | 强调色 · 星星、惊喜提示 |
| **Sky Blue** | `#79C9E8` | 辅助色 · 背景、信息卡片 |
| **Cream White** | `#FFF2D8` | 基础色 · 页面背景、卡片 |
| **Pure White** | `#FFFFFF` | 辅助色 · 卡片内部、文字反差 |

## 补充颜色

| 名称 | HEX | 用途 |
| --- | --- | --- |
| Deep Red | `#C92F42` | Hover、按下状态 |
| Dark Green | `#218653` | 深色绿色文字、图标 |
| Warm Orange | `#FF914D` | 活动、装饰 |
| Candy Pink | `#FF8FB3` | 贴纸、节日装饰 |
| Dark Text | `#493B3B` | 正文、标题 |
| Muted Text | `#817575` | 次要信息 |
| Locked Gray | `#D8D2CC` | 未开放日期 |

## 推荐使用比例

- 50% — Cream White `#FFF2D8`
- 20% — Christmas Red `#F04452`
- 15% — Mint Green `#38B879`
- 10% — Sky Blue `#79C9E8`
- 5% — Cream Yellow `#FFD45A`

这套颜色以奶油白维持阅读舒适度，用红绿建立圣诞识别，再用黄蓝增加儿童产品的活泼感。

> **注意：** 黄色和天空蓝更适合做背景或装饰，不建议直接用作白底上的小字号文字，以免对比度不足。
